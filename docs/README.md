# Canvas Toolkit guides

Canvas Toolkit draws controls on an HTML canvas. Create one `CApplication`, then construct widgets and attach layouts. Parent widgets own their children and application roots are painted by the application.

- [Getting started](getting-started.md) creates a responsive application.
- [Layouts](layouts.md) covers preferred sizes, bounds and scrolling.
- [Signals and slots](signals-and-slots.md) connects controls to application actions.
- [Model/View](model-view.md) separates data, presentation and editing.
- [Custom painting](custom-painting.md) implements a canvas widget.
- [Styling](styling.md) covers palettes, fonts, icons and styles.
- [Focus and dialogs](focus-and-dialogs.md) explains keyboard order and modal windows.
- [Files](files.md) collects local files for an explicit application action.

The API reference groups signals separately and displays inherited members on derived classes. Members tagged `@internal` are excluded.
